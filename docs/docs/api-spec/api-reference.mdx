# API Документация

## Общая информация

**Base URL (локально):** `http://127.0.0.1:8080`
**Base URL (прод):** `https://opengate.up.railway.app`

**Формат:** JSON (кроме специальных эндпоинтов)

**Авторизация:** Bearer token (кроме публичных эндпоинтов)

```
Authorization: Bearer <token>
```

## OpenAPI / Swagger Спецификация

Ниже приведена полная спецификация API в формате **OpenAPI 3.0.3** (совместимом с Swagger).

### Публичные эндпоинты

#### GET /

Возвращает Telegram Mini App фронтенд.

**Ответ:** HTML

#### GET /health

Проверка работоспособности сервиса.

**Ответ:**
```json
{
  "status": "ok"
}
```

### Авторизация

#### POST /auth/login

Вход через Telegram Mini Apps. Принимает `initData` из `window.Telegram.WebApp.initData`.

**Заголовки:** `Content-Type: application/json`

**Тело:**
```json
{
  "init_data": "query_id=...&user=...&auth_date=...&hash=..."
}
```

**Ответ (200):**
```json
{
  "token": "abc123...",
  "user": {
    "id": 123456789,
    "first_name": "Иван",
    "last_name": "Петров",
    "username": "ivan_petrov",
    "photo_url": "https://..."
  },
  "expires_at": "2026-08-12T10:00:00Z"
}
```

**Ошибки:**
- `401` — невалидная подпись initData
- `403` — доступ запрещён (не в ALLOWED_IDS)
- `429` — слишком много попыток входа

:::note Rate Limiting
Максимум 10 попыток входа в минуту с одного IP. Настраивается через `LOGIN_RATE_LIMIT` и `LOGIN_RATE_WINDOW_SECONDS`.
:::

#### GET /auth/me

Возвращает данные текущего пользователя.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ (200):**
```json
{
  "id": 123456789,
  "first_name": "Иван",
  "last_name": "Петров",
  "username": "ivan_petrov",
  "photo_url": "https://..."
}
```

#### POST /auth/logout

Завершает сессию.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ:**
```json
{
  "ok": true
}
```

### Управление ключами

#### GET /keys/status

Статус ключей серверов.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ (200):**
```json
{
  "path": "C:\\app\\data\\keys.json",
  "exists": true,
  "updated_at": "2026-08-11T10:00:00Z",
  "size_bytes": 1024,
  "total_keys": 34
}
```

#### POST /pull-keys

Запускает обновление ключей из удалённого источника.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ (200):**
```json
{
  "command": ["python", "scripts/pull_keys.py", "--once"],
  "returncode": 0,
  "stdout": "...",
  "stderr": ""
}
```

:::note Автоматическое обновление
Ключи автоматически обновляются каждые 30 минут через планировщик.
:::

### Подписки

#### GET /subscription.txt

Возвращает текстовую подписку для Happ.

**Доступ:** подписанный URL ИЛИ авторизованная сессия

**Ответ:** `text/plain`

```text
#profile-title: OpenGate 123456789
#profile-update-interval: 24
vless://server1...
vless://server2...
```

**Ошибки:**
- `403` — подписка не активна
- `404` — ключи не найдены

#### GET /subscription.json

Возвращает JSON-подписку для Happ.

**Доступ:** подписанный URL ИЛИ авторизованная сессия

**Ответ:** `application/json`

```json
{
  "subscription": {
    "id": "default",
    "status": "active",
    "params": {
      "profile-title": "OpenGate 123456789"
    }
  },
  "servers": [
    {
      "uri": "vless://...",
      "remarks": "Region",
      "meta": {
        "serverDescription": "Region"
      }
    }
  ]
}
```

### Happ Deep Links

#### GET /subscription-link

Возвращает рабочую Happ deep link для текущего пользователя.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ:** `text/plain`

```text
happ://crypt5/fzvd6ovH6kXv8JwfbZTkkt9l1469Bt4ur1mGJXcE7rRtyf5RA9FXt0b0X82pvg...
```

**Логика:**
1. Проверка in-memory кэша (5 минут)
2. Проверка БД (24 часа)
3. Вызов crypto API (если нет в кэше/БД)

#### GET /subscription-redirect-url

Возвращает подписанный URL на `/subscription-redirect-302`.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ:** `text/plain`

```text
https://opengate.up.railway.app/subscription-redirect-302?expires=1786549282&uid=123456789&sig=09f8917f...
```

#### GET /subscription-redirect-302

Мгновенный 302-редирект на Happ deep link.

**Доступ:** подписанный URL (expires + uid + sig)

**Ответ:** 302 Redirect на `happ://` ссылку

### Управление процессом подписки

#### POST /build-subscription

Запускает процесс сборки подписки.

**Заголовки:** `Authorization: Bearer <token>`, `Content-Type: application/json`

**Тело:**
```json
{
  "active_minutes": 5,
  "port": 8000,
  "name": "My Subscription",
  "slug": "my-subscription",
  "profile_title": "My Subscription",
  "force_restart": false
}
```

**Параметры:**
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `active_minutes` | int | 5 | Время жизни процесса (1-60) |
| `port` | int | 8000 | Порт для сервера |
| `name` | string | null | Название подписки |
| `slug` | string | null | Slug подписки |
| `profile_title` | string | null | Заголовок профиля |
| `force_restart` | bool | false | Принудительный рестарт |

**Ответ (200):**
```json
{
  "running": true,
  "pid": 12345,
  "started_at": "2026-08-11T10:00:00Z",
  "expires_at": "2026-08-11T10:05:00Z",
  "public_url": null,
  "returncode": null,
  "command": ["python", "-u", "scripts/build_subscription.py", "--serve", "--port", "8000"],
  "logs": []
}
```

#### GET /build-subscription/status

Статус процесса сборки подписки.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ (200):**
```json
{
  "running": true,
  "pid": 12345,
  "started_at": "2026-08-11T10:00:00Z",
  "expires_at": "2026-08-11T10:05:00Z",
  "public_url": "https://example.ngrok-free.dev/subscription.txt",
  "returncode": null,
  "command": ["python", "-u", "scripts/build_subscription.py", "--serve", "--port", "8000"],
  "logs": [
    "Wrote data/subscription.txt (34 entries)",
    "Public HTTPS URL (ngrok): https://example.ngrok-free.dev/subscription.txt"
  ]
}
```

#### POST /build-subscription/stop

Останавливает процесс сборки подписки.

**Заголовки:** `Authorization: Bearer <token>`

**Ответ (200):**
```json
{
  "running": false,
  "pid": 12345,
  "started_at": "2026-08-11T10:00:00Z",
  "expires_at": "2026-08-11T10:05:00Z",

  "returncode": 1,
  "command": ["python", "-u", "scripts/build_subscription.py", "--serve", "--port", "8000"],
  "logs": ["..."]
}
```

## Коды ошибок

| Код | Описание |
|-----|----------|
| `400` | Невалидный запрос |
| `401` | Не авторизован / невалидная подпись |
| `403` | Доступ запрещён |
| `404` | Не найдено |
| `429` | Слишком много запросов (rate limit) |
| `500` | Внутренняя ошибка сервера |
| `504` | Таймаут команды |
